The brief.

School materials need to communicate at different scales: a classroom poster has to explain an idea, while a roll-up banner has to make a project brief easy to recognise. The returning-client work included both.

02 / Decisions & responsibility

My contribution.

I coordinated the work with the client and team. The banners repeat a common hierarchy for the profession, brief, commissioning organisation and end product. The percentages poster uses familiar objects and grouped explanations to make the learning sequence visible.
